具体安装位置与回退

Clash Verge Rev

「订阅」→ 右键你的机场 →「扩展脚本」→ 全文替换 → 保存。全局脚本与其它覆写保持默认；不要把这份代码粘进 YAML 扩展配置，不要叠加 V4。客户端保持规则模式，系统代理照常使用。

FlClash

你的机场订阅菜单 →「扩展」（旧版叫「覆写」）→「扩展模式：脚本」→「前往配置脚本」→ 新建、粘贴、保存 → 返回该订阅选中并绑定脚本 → 重新应用。只保存不绑定不会完成安装。不要导入为完整 YAML 自定义配置。

回退

Verge 将订阅扩展脚本恢复为 function main(config) { return config; } 并重新应用原订阅。FlClash 解除该脚本绑定或切回标准模式。两个客户端不要同时接管系统代理 / TUN。

稳定模式与完整模式，有什么差别？
项目stable · 默认moyu-full · 可选
机场原规则保留顺序与 MATCH 去向由新规则接管
新增远程规则源0 个21 个；广告开启后 22 个
分类覆盖常见域名 + 原机场规则沿用 V4 的远程规则集
启动依赖不新增规则下载；原依赖仍存在需要规则缓存或可用下载通道

切换方法：把顶部 ruleMode: "stable" 改成 ruleMode: "moyu-full"，保存脚本后重新应用原始订阅。不要将最终运行配置当成原订阅。稳定模式不是完整规则集的离线镜像。

修复范围与测试边界

缺失字面量 PROXY 的规则改指真实存在的组；未知其它错误不猜测为直连。检查重名、缺失引用、已知静态依赖循环和重复应用；异常不会留下半修改的输入。保留全部真实节点及 provider，不按地区或倍率筛节点。DNS、TUN、端口、模式、IPv6 和证书验证不改。
